# MECHROBOT

A modern full-stack web application developed for MECHROBOT. The project provides a responsive user interface along with a Node.js/Express backend for managing application data, authentication, administration, media uploads, and other website functionality.

## 🚀 Tech Stack

### Frontend

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Axios
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt.js

### Other Services

- MongoDB Atlas
- Cloudinary
- Nodemailer
